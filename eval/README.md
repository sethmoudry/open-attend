# MedGemma Scribe — Evaluation Pipeline

Reproducible evaluation suite for the Scribe clinical documentation system.
Feeds data through the **actual backend** — same ASR models, same LLM merge, same SOAP generation.

## Quick Start

```bash
# 1. Install dependencies
poetry install --with eval

# 2. Start the backend
cd backend && uvicorn main:app --host 0.0.0.0 --port 8000 &

# 3. Run full evaluation
bash eval/run_eval.sh

# Or run individual stages
bash eval/run_eval.sh --stage1-only   # Transcription only
bash eval/run_eval.sh --stage2-only   # Note generation only
```

## Metrics

### Stage 1 — Transcription (Fareez OSCE, n=25)

| Metric | What it measures | Benchmark |
|--------|-----------------|-----------|
| MedASR WER | Medical ASR word error rate | Google MedASR: 5.2% (dictation) |
| Whisper WER | General ASR word error rate | — |
| Merged WER | Dual-ASR + LLM fusion accuracy | Should beat both individuals |
| MEER | Medical Entity Error Rate | — |

### Stage 2 — Note Generation (ACI-Bench, n=80)

| Metric | What it measures | Benchmark |
|--------|-----------------|-----------|
| ROUGE-1/2/L | N-gram overlap with gold notes | GPT-4: ~0.50/0.25/0.40 |
| Entity Completeness | % relevant entities captured | — |
| Entity Faithfulness | % entities grounded in dialogue | — |
| LLM-Judge Score (/25) | Clinical quality (5 dimensions) | — |

## Datasets

- **Fareez OSCE** (Stage 1): 25 audio files from the Fareez et al. (2022) OSCE dataset.
  Specialty-balanced: DER, CAR, GAS, MSK, RES. Downloaded from Figshare.
- **ACI-Bench** (Stage 2): 80 encounters from the ACI-Bench clinical NLP benchmarks
  (Yim et al., 2023). Downloaded from Figshare.

## Reproducibility

- **Entity cache**: LLM-based entity extraction is cached to disk (`eval/results/.entity_cache/`).
  Same text always produces the same entities across runs. First run: ~340 LLM calls.
  Second run: 0 entity extraction calls (all cached).
- **Checkpointing**: Both stages write results incrementally to CSV. If interrupted,
  re-running skips completed IDs.
- **Configuration**: All hyperparameters in `eval/config.py`.

## Known Limitations

1. **Batch vs chunked ASR**: Eval processes whole audio files; production chunks at 15s
   intervals. Batch WER may be slightly better than production.
2. **LLM-as-judge circularity**: Gemini Flash Lite judges notes generated by Gemini Flash Lite.
   Acknowledged as limitation — independent human eval would be stronger.
3. **Entity extraction non-determinism**: Initial LLM extraction is non-deterministic.
   Disk cache ensures identical scores across re-runs, but cache must be preserved.
4. **ACI-Bench dialogues are synthetic**: Not real patient encounters.
5. **Speaker accuracy not evaluated**: Non-trivial alignment problem (cluster IDs → roles →
   turn alignment). Dropped to nice-to-have.
